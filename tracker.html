One-click publish directly to your GitHub repository. Changes go live in ~30 seconds. Your token is saved to this browser only and never included in the exported file.
One-time setup1. Create a free GitHub account and a new public repository.
2. Go to repo Settings → Pages → Deploy from main branch, / (root).
3. Go to github.com/settings/tokens → Generate new token (fine-grained) → Contents: Read & Write for this repo.
4. Fill in the fields below and click Save, then Publish.
