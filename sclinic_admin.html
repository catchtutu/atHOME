🔥 Firebase Configuration

Setup requiredPaste your Firebase project config into both HTML files where indicated. Both files must reference the same project and database.
Recommended database rulesIn Firebase Console → Realtime Database → Rules, set:
{"rules": {"sc_handbook": {".read": true, ".write": true}}}
For a production deployment, restrict by authenticated session or apply per-path rules.

Firebase path structure used:
sc_handbook/codeIndex/{CODE} → userId
sc_handbook/users/{userId}/profile → {name, code, registeredAt, lastSeen}
sc_handbook/users/{userId}/progress/{id} → {ticked, date}
sc_handbook/signoffs/{userId}/{id} → {signed, signedBy, signedDate}
sc_handbook/contacts/{key} → contact fields
